## 👋 Sobre este repositorio

Este repositorio reúne mis ejercicios y prácticas de **Java**, realizados para aprender los fundamentos de la programación y mejorar progresivamente mi forma de escribir y organizar código.

Los ejercicios se desarrollan principalmente en **Apache NetBeans** y se mantienen actualizados mediante **Git y GitHub Desktop**.

> 🚧 **Proyecto en desarrollo:** iré añadiendo nuevos ejercicios, correcciones y mejoras conforme avance el curso.

## 🗂️ Organización

Los ejercicios están distribuidos en **paquetes Java**, según la práctica o el contenido trabajado. La estructura concreta puede variar a medida que incorpore nuevos ejercicios.

```text
Ejemplos_Para_Clases_Programacion/
├── README.md
├── .gitignore
├── src/
│   ├── Ejemplo_If/
│   ├── Ejemplo_Switch/
│   └── ...
├── nbproject/         # Si el proyecto utiliza NetBeans con Ant
└── build.xml          # Si el proyecto utiliza NetBeans con Ant
```

## 🚀 Cómo ejecutar los ejercicios

1. Clona el repositorio o descárgalo como archivo ZIP.
2. Abre **Apache NetBeans**.
3. Selecciona **File → Open Project** y abre la carpeta del proyecto, si NetBeans la reconoce como proyecto.
4. Busca el paquete y la clase que quieras ejecutar.
5. Haz clic derecho sobre la clase y selecciona **Run File**.

**Nota:** varios ejercicios tienen su propio método `main`, por lo que se ejecutan individualmente. Si NetBeans no reconoce la carpeta como un único proyecto, abre los proyectos NetBeans que contenga o importa los archivos fuente en un proyecto Java.
